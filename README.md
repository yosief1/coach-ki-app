# Coach-KI

Eine mobilfähige, persönliche Fußball-KI-App mit:

- Registrierung mit E-Mail-Flow
- Spielerprofil
- persönlichem Home-Dashboard
- KI-Coach-Dialog
- Training- und Entwicklungslogik
- Match- und Zielstruktur
- KI-Team und Wissensmodulen
- lokaler Speicher in Browser/LocalStorage

Wichtig:
- Diese Version ist ein funktionierender MVP-Prototyp.
- Die E-Mail-Bestätigung ist ein Demo-Flow, damit der Registrierungsprozess auf dem Handy direkt getestet werden kann.
- Für echte Backend-Authentifizierung und echte E-Mail-Delivery müsste eine echte Server- und Mail-Infrastruktur hinzugefügt werden.

Open the app in the browser and use the registration flow to test it immediately.
